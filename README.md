## 🌷 Welcome, player!

**SYSTEM ERROR** is a 2D Stray Kids fan game made with HTML Canvas. Travel through seven worlds, take on 21 missions, and help restore the system one level at a time.

> ✨ **Your characters, your art:** each world uses its own portraits from **Pixel world character.zip**. The larger art from **SKZ PIXEL PNG.zip** appears only in the animated character introductions.

## 🎮 Start playing

### Use the complete project

Download and extract `system-error-skz-campaign-complete.zip`, then serve the folder locally or publish it with GitHub Pages.

### Or upload in three parts

1. Download all three `system-error-skz-campaign-part-*.zip` files.
2. Extract each one into the **same folder** and let the files merge together.
3. Upload the combined contents to the root of a single GitHub repository.
4. In GitHub, open **Settings → Pages**, choose your branch and the root folder, then save.
5. Visit the published site and open `index.html`.

Each part has fewer than 100 files. Keep the extracted files together; don’t put each ZIP’s contents in a separate folder.

> 🍓 Opening `index.html` directly from File Explorer can cause browser restrictions on images and audio. GitHub Pages or a local web server works better.

## 🕹️ Controls

Each level’s intro shows its controls. Here are the usual ones:

| Button | What it does |
|:--|:--|
| **A / D** or **← / →** | Move |
| **Space** | Jump or use the main action |
| **Q** | Switch phase or gravity |
| **J** | Fire |
| **Shift** | Dash |
| **P** or **Esc** | Pause / resume |

Touch buttons appear on smaller screens. Your campaign progress is saved in your browser on that device. ♡

## 📦 Project map

- `index.html` — the arcade hub, world select, and character select
- `campaign.html` — the Canvas game screen and animated character intro
- `campaign-data.js` — worlds, levels, goals, and controls
- `campaign.js` — game logic, HUD, results, and unlock progress
- `retro-arcade.html` / `retro-arcade.js` — the nine new classic-style arcade prototypes
- `karma-firewall.html`, `karma-stack.html`, `do-it.html` — the two existing KARMA mini-games and DO IT crowd hunt
- `game-design-guide.pdf` — the original design guide
- `chars-w1-*.webp` … `chars-w9-*.webp` — portraits cropped from the matching world roster sheets
- `member-art-*.webp` — intro-only character art
- `scene-*.webp` and `roster-world-*.webp` — world scenes and original roster sheets
- Standalone prototype pages and shared assets
